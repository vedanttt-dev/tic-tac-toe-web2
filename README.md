# Tic-Tac-Toe Chaos Edition 🎮

A modern, feature-rich Tic-Tac-Toe web game with stunning visual effects, multiple game modes, and AI opponents.

## ✨ Features

### 🎮 Game Modes
- **Normal Mode**: Classic Tic-Tac-Toe rules - first to get 3 in a row wins
- **Chaos Mode**: Strategic twist - only 3 active moves allowed per player

### 🤖 AI Opponents
- **Easy**: Perfect for beginners
- **Medium**: Challenging gameplay
- **Hard**: Advanced AI tactics

### 🎨 Visual Effects
- **Particle System**: Dynamic background particles
- **Glass Morphism UI**: Modern, translucent design
- **Smooth Animations**: Hover effects, transitions, and win celebrations
- **Confetti Effects**: Victory celebrations
- **Sound Effects**: Audio feedback for moves and game events

### 📊 Features
- **Local Multiplayer**: Play with friends on the same device
- **Leaderboard**: Track high scores for both game modes
- **Player Statistics**: Detailed gameplay stats
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **Win Line Animation**: Visual indication of winning combinations

## 🎯 How to Play

### Basic Rules
1. Players take turns placing X's and O's on a 3x3 grid
2. First player to get 3 in a row (horizontal, vertical, or diagonal) wins
3. If all 9 squares are filled without a winner, it's a draw

### Chaos Mode Rules
- Each player can only have 3 active moves on the board
- When a player places their 4th move, their oldest move is automatically removed
- This creates dynamic, strategic gameplay where board positions constantly change

### Controls
- **Mouse/Touch**: Click on any empty square to make your move
- **Buttons**: Use on-screen buttons for navigation and game controls

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and game structure
- **CSS3**: Advanced styling with:
  - CSS Grid and Flexbox for layouts
  - CSS Variables for theming
  - Animations and transitions
  - Glass morphism effects
- **Vanilla JavaScript**: Game logic and interactions
- **Web Audio API**: Dynamic sound generation
- **Canvas API**: Particle system for visual effects


### Modifying AI Difficulty
The AI logic is implemented in JavaScript. You can adjust the difficulty by modifying the `aiMove()` function and its difficulty-specific logic.
